WORTHLESS CHECK
Release 1.0.0-rc65 - configurable organization headings

SET YOUR IDENTITY
Sign in as an application Administrator. Open Office Information, enter Organization / office name, optional heading lines 2-4, optional workspace name, and your own address/contact details. Save Office Information. The banner and newly generated standard receipts/reports use those values. Blank heading fields display Worthless Check. No circuit/county/state heading is inferred from imported legacy fields. State/region is optional. Staff cannot edit organization settings.

COMPATIBILITY
Office 1 uses internal division key troy and group PikeCountyWCUsers; Office 2 uses enterprise and EnterpriseWCUsers. Data paths remain C:\ProgramData\PikeCountyWC-ServerEvaluation\Data\wc.sqlite and EnterpriseData\wc.sqlite. Executable remains PikeCountyWC.exe. New installation folder defaults to Worthless Check; upgrades may retain the existing folder. These internal identifiers do not create printed DA/county branding.

OUTPUT
Standard receipts and reports use saved headings. Already exported files are untouched. Reprints regenerate headings using current organization settings while retaining the saved financial balances. Archived original agency forms/signatures are blocked, pending organization-specific template work and review. The original assets are preserved for historical reference.

OPERATIONS
Use the local server SQLite databases, separate Windows sessions and office access groups. Application roles are separate from Windows permissions. Staff can create new cases and record payments; other legacy-record creation, existing-record edits, configuration and reconciliation require Administrator. Preserve complete backups and review any upgrade independently. Never copy an open main SQLite file alone or discard journals.

No installation or live-data update is authorized by this source/build. Keep the three existing Troy receipt pairs pending.
