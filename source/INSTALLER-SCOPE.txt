Worthless Check - personal empty workspace edition
Release 1.0.0-rc66

Windows 11 / Windows Server 2022 x64 Desktop Experience. A normal launch uses the signed-in Windows user's Local AppData\WorthlessCheck\Data\wc.sqlite. It starts with no users, cases or payments. Create your first Administrator and leave sample cases unchecked for an empty workspace.

The installer copies application files and shortcuts. It does not create server access groups, alter shared database permissions, import office history, or reset existing records. Reopening uses the same personal workspace and preserves its contents.

Set your custom organization heading in Office Information. No old organization heading is inferred. Archived agency-specific forms remain disabled until custom forms are reviewed.

An existing shared workspace requires an explicit --division office1 or --division enterprise launch and its existing Windows access permissions. Existing shared database directories remain compatible; they are not selected by the default shortcut. Former office-specific launchers must be reviewed and updated separately. Installing this release does not authorize a production cutover.
