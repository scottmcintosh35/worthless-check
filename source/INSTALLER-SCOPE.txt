Pike County Worthless Check Unit - Windows Server Evaluation
Deployment candidate 1.0.0-rc56

This installer is for Windows Server 2022 Datacenter with Desktop Experience.
It installs a self-contained x64 desktop application for multiple Remote Desktop
users on the same server, with separate local databases for Troy DA and Enterprise DA.

The first Administrator setup includes fictional sample cases by default.
No actual case records or passwords are included in this installer.

This is an evaluation deployment, not an approved production cutover. Official
fund distribution, specialized legal forms and the legacy-data exceptions still
require verification. Read DEPLOYMENT-READ-ME.txt for setup and test instructions.

The installer creates the local Windows groups PikeCountyWCUsers (Troy DA) and
EnterpriseWCUsers (Enterprise DA). Assign staff to their division group and
assign selected staff to both groups.
Application users and passwords are managed separately inside the program.

Updates/uninstall preserve the shared evaluation database and its backups.
Close all application sessions and take a backup before updating the software.
